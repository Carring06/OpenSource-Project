# 平衡车实现直立：修改重点分析

## 全部修改点一览

共 7 处修改，涉及 6 个文件：

A. MPU6050_CONFIG 寄存器 0x06 -> 0x00（DLPF 5Hz -> 260Hz）
B. 新增 MPU6050_Calibrate 自动校准函数
C. 新增 GY_Offset / AngleAcc_Offset 全局变量替代硬编码偏移
D. 重写 Complementary_Filter（低通预滤波 + 动态Alpha + 偏移量校准 + dt传入）
E. tim_callback.c 调用传参 Complementary_Filter(0.010f, DifSpeed)
F. main.c K1 处理器增加校准 + PID_Init + Angle = AngleAcc_Filter
G. 串口 plot 输出从速度改为角度数据

### 决定性修改点（真正让小车从"无法直立"变成"能直立"的因素）

修改 A（DLPF 5Hz -> 260Hz）是唯一真正决定性的因素。原始代码的 19ms 传感器延迟对 10ms 控制周期是致命的，PID 永远在追赶过时的数据，不可能收敛。

修改 F 中的 Angle = AngleAcc_Filter 是第二关键的因素。没有这一行，启动后角度需 1.5 秒才能收敛到真实值，这 1.5 秒内 PID 输出异常，足以让小车倾倒。

修改 B（MPU6050_Calibrate）是第三关键的因素。没有它，偏移量是别人的芯片值，角度基准从一开始就是歪的。

这三项缺一不可，都是"是否能直立"的决定性条件。其余的修改（动态Alpha、低通滤波等）只影响"直立得是否平稳"，不影响"能否直立"这个二值结果。

## 一、函数介绍

### 1. MPU6050 驱动 (User/Device/Src/MPU6050.c / Inc/MPU6050.h)

MPU6050 是 6 轴惯性传感器（3 轴加速度计 + 3 轴陀螺仪），通过 I2C 总线与主控通信。

涉及的主要函数：

MPU6050_Init 初始化函数，配置 MPU6050 的工作模式，包括退出睡眠、设置采样率、配置数字低通滤波器 DLPF 截止频率、量程等。初始化阶段在 main.c 第 131 行调用一次。

MPU6050_GetData0 读取 6 轴原始数据，存入传入的指针变量。在 MPU6050_Calibrate 和 Complementary_Filter 中被调用。

MPU6050_Calibrate 新增的上电校准函数。采集 200 组静止状态下的传感器数据，计算陀螺仪 Y 轴零偏 GY_Offset 和加速度计角度偏移 AngleAcc_Offset。在 K1 按键按下启动时调用，执行耗时约 1 秒，需要小车水平静止放置。

GY_Offset 和 AngleAcc_Offset 新增的全局变量，存储校准结果。互补滤波中自动使用，替代原来写死的常数值 -= 31 和 -= 2.49。

### 2. 互补滤波 (User/Algorithm/Src/CompFilter.c)

互补滤波是平衡车的核心算法，将加速度计（长期稳定、短期噪声大）和陀螺仪（短期精确、长期漂移）融合成稳定的角度估计。

核心变量：

AngleAcc 加速度计瞬时角度，通过 atan2(AccX, AccZ) 计算，对振动敏感。

AngleGyro 陀螺仪积分角度，通过 Angle + GyroY * dt / 灵敏度 计算，短时精确但随时间漂移。

Angle 融合后的最终角度，PID 控制环使用此值。

AngleAcc_Filter 经一阶低通滤波后的加速度计角度，滤除高频振动噪声。

Alpha 融合权重。介于 0 和 1 之间，越大越信任加速度计，越小越信任陀螺仪。

Complementary_Filter(float dt, float DifSpeed) 函数签名。dt 是两次调用的时间间隔，DifSpeed 是左右轮差速。函数体内完成加速度计角度计算、偏移校准、低通预滤波、陀螺仪积分、动态 Alpha 计算、最终融合。在 TIM1 中断中以 10ms 周期调用。

### 3. 主循环 (Core/Src/main.c)

main 函数中的 while(1) 循环处理按键和 OLED 显示。

K1 按键被配置为启动/停止开关。首次按下执行校准和初始化，再次按下停止。

## 二、关键修改（按重要性排序）

### 关键修改一：MPU6050_CONFIG 寄存器 DLPF 配置

文件位置：MPU6050.c 第 23 行

原始代码：
    MPU6050_WriteData(MPU6050_CONFIG, 0x06);

修改后代码：
    MPU6050_WriteData(MPU6050_CONFIG, 0x00);

CONFIG 寄存器的 DLPF_CFG 位控制数字低通滤波器的截止频率。0x06 是带宽最窄的配置，陀螺仪信号经过 DLPF 后带宽仅 5Hz，产生约 19ms 的群延迟。也就是说当小车倾斜 1 度时，要等 19ms 才能从传感器读到这个变化。

PID 控制周期是 8-10ms，读到数据时小车已经倒了更多，PID 永远在追赶滞后的数据，始终无法收敛。这是"无法完全直立"的根本原因。

改为 0x00 后 DLPF 旁路，带宽 260Hz，延迟约 1ms。传感器与控制器同步，PID 能及时响应姿态变化。

原始版本调了大量 PID 参数（Kp=14，Ki=0.1，Kd=1）加上输出偏移补偿，但传感器延迟是 PID 无法克服的物理问题。修改后即使 PID 参数不变，响应速度也显著提升。

### 关键修改二：角度瞬时初始化 Angle = AngleAcc_Filter

文件位置：main.c 第 160 行

原始代码没有这一行，Angle 全局变量默认值为 0。

修改后代码：
    Angle = AngleAcc_Filter;

原始版本互补滤波 Alpha = 0.028，时间常数 τ = 8ms / 0.028 ≈ 286ms，需要约 1.5 秒才能收敛到真实角度的 99%。启动后这 1.5 秒内，角度误差大，PID 输出异常，小车向一边倒。

Angle = AngleAcc_Filter 让融合角度从启动瞬间就等于加速度计读数。由于 AngleAcc_Filter 已经过偏移校准和低通滤波，接近真实值。PID 第一拍就能在正确基准上工作。

### 关键修改三：自动校准替代硬编码偏移

新增 MPU6050_Calibrate 函数（MPU6050.c 第 82-126 行），循环 200 次读取原始数据，累加 gy 和 atan2(ax,az)，每 5ms 一次。平均后取反得到 GY_Offset 和 AngleAcc_Offset。

原始代码直接在互补滤波中写死：
    MPU6050_Data.Gyro_Y  -= 31;   // CompFilter.c 第 14 行
    AngleAcc -= 2.49;              // CompFilter.c 第 18 行

每一颗 MPU6050 的零偏不同，每台小车的传感器安装角度也不同。从参考工程复制的 -= 31 和 -= 2.49 只能适配那一块特定芯片。校准错误导致角度基准偏差，PID 一直在错误基准上努力。

自动校准解决这个问题。200 次采样取平均，随机噪声被平滑。注意校准时小车必须水平静止，否则结果比硬编码更差。

### 关键修改四：重写互补滤波

文件：CompFilter.c 全部重写

1. 偏移校准方式：从硬编码改为使用 GY_Offset 和 AngleAcc_Offset 变量，由校准函数自动写入。

2. 加速度计低通预滤波：
   原始：直接用原始加速度计角度做融合。
   修改：AngleAcc_Filter = 0.8 * AngleAcc_Raw + 0.2 * AngleAcc_Filter。
   滤除高频振动噪声，滤波系数 0.8 兼顾响应速度和噪声抑制。

3. 陀螺仪积分时间：
   原始：写死 0.008（与 Count0=8 的硬件配置绑定）。
   修改：使用 dt 参数传入（当前传入 0.010f），解耦滤波逻辑与硬件配置。

4. 融合权重 Alpha：
   原始：固定 Alpha = 0.028，始终 97.2% 信任陀螺仪。
   修改：Alpha = fabs(AngleAcc_Filter - AngleGyro) * 0.005 + 0.005，范围 0.005-0.02。
   当加速度计和陀螺仪角度差异大时增大 Alpha 快速修正，一致时减小 Alpha 以抑制噪声。

## 三、辅助修改

### 修改五：tim_callback.c 调用传参

Complementary_Filter() 改为 Complementary_Filter(0.010f, DifSpeed)，匹配新的函数签名。

### 修改六：K1 处理器逻辑调整

停止时 PID_Init 移到启动时执行，确保每次启动积分清零。增加校准调用和角度初始化。

### 修改七：串口 plot 输出

从速度数据改为三个角度值（Angle、AngleAcc、AngleGyro），便于串口绘图工具观察滤波效果。

## 四、总结

四个关键点按优先级排列：

1. DLPF 5Hz -> 260Hz：消除 19ms 传感器延迟，让控制环读到实时数据（最重要）
2. Angle = AngleAcc_Filter：启动瞬间角度归零，消除 1.5 秒收敛期
3. MPU6050_Calibrate 自动校准：适配当前芯片零偏，代替无法移植的硬编码
4. 互补滤波重写：低通预滤波 + 动态 Alpha 提升角度估计的质量和适应性

前两个解决了直立的基本前提（能读到及时的数据 + 启动时角度正确），后两个优化了长期运行的稳定性。

## 五、当前问题

1. MPU6050_Calibrate 在 K1 按下时执行，耗时约 1 秒，期间主循环阻塞。
2. Calibrate 依赖小车竖直静止，否则偏移量不准。
3. GY_Offset 不依赖姿态却每次都校准，与 AngleAcc_Offset 绑定在一起。
4. Complementary_Filter 的 DifSpeed 参数传入但未在计算中使用。
